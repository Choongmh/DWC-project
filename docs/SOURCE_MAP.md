# Project sources

- `src/`, `tests/`, `models/` and `outputs/`: final local submission archive.
- `data/raw/`: nine organizer workbooks from the local T2 folder.
- `data/processed/`: prepared T1 tables and the saved T2 evaluation cache.
- `presentations/`: original team slides.
- `dashboard/exon_recovered.pbix`: recovered original Power BI report.
- `video/t2 exon.mp4`: available T2 video, not a verified complete-team submission video.
- `docs/original/`: briefing, T1 hand-off and T2/T3 presentation reference PDFs.
- `learning/`: beginner study workbook created for this portfolio edition.

The main branch contains the integrated project; task branches retain their relevant files and dependencies. Original authorship is recorded in ATTRIBUTION.md. Older presentation claims should be read with PRESENTATION_CORRECTIONS.md.

The recovered Power BI report's native open/refresh and the learning workbook's rendered page layout remain unverified. No final full-team video or public YouTube URL was identified locally. Current upstream completeness has not been verified against authenticated remote access.
